# 组装清单（自己留着）

## 要准备的
- 双面胶：把 Wi‑Fi 天线贴在机身内侧顶部。
- 一根细针或小一字螺丝刀：拆前框、后盖时用。
- 不用螺丝，也不用胶水。

## 顺序
1. **麦克风**：INMP441 小圆板（⌀14mm）按进机身左侧内壁的圆环（高 6mm），收音孔朝外，对准外面那一圈像素圆形收音孔；按到底时圆环内侧三个卡点会扣住板子。圆环是横着打印的，孔顶可能有点塌，按不进去就用小刀把孔顶刮一下。线从圆环朝机身里的口直接出来。
2. **板子**：上下沿的插头先插好线（上沿到内壁留 4mm、下沿留 9mm，线往板子背面走）。板子屏幕朝前，从机身前口放进去，把板子四角的安装孔套进左右内壁四个弹簧托台上的定位销，板子就自己定好位了，这时 USB‑C 正好对准机身右侧开口。装的时候可以把机身前口朝上平放，板子放上去不会滑。
3. **前框**：前框对准机身前口，四角均匀用力直接按进去，上下沿各两个卡扣“咔”一声扣进机身上下壁的窗口。前框背面那 **4 根小柱子**就是用来压住板子的：柱子端面正对着板子四角的安装孔压下去，中间的小孔让开定位销的尖，柱子把板子往后压在弹簧托台上。托台的横梁会被压弯一点，一直把板子往前顶，所以前框扣上后板子是被弹簧顶紧的，不会晃；按前框时会感觉到一点弹力，按到底“咔”一声就扣住了。
4. **雷达线**：P1 就在 USB‑C 旁边，机身右侧开口已经加高把它包进去了，雷达线从右侧开口直接插到 P1，雷达放在机身外面。
5. **喇叭**：喇叭按进后盖内侧的方框里，方框上下两边的卡点会扣住它；线从方框左边的槽口出来，接到板子的 Speak 口。
6. **电池**：603450 电池按进后盖内侧左下的矮框里，两条长边的卡点扣住；线从框右侧的开口出来，接到板子的 BAT 口。
7. **Wi‑Fi 天线**：贴在机身内侧顶部，附近别有金属。
8. **后盖**：长线塞进机身，和前框一样，对准后直接按进去，四个卡扣扣上。
9. **支架**：两条腿的插销对准机身底部的两个方孔往上推，插销是开叉的，推到底“咔”一声，尖端的倒钩扣在内侧套筒顶上，拿起机器支架也不会掉。

## 拆开
先捏住支架用力往下拔（插销倒钩的卡面是斜的，用力就能拔出来）。机身上壁和下壁各有四个小窗口：靠前的两个对应前框，靠后的两个对应后盖。先用细针同时顶住上壁两个窗口里的倒钩，把盖子上沿往外拉出一点；再顶住下壁两个窗口，把整个盖子拉出来。前框有弹簧托台往外顶，倒钩一松开它会自己弹出来一点。

## 改尺寸
所有尺寸都在 `model.py` 开头。板子顶得太松或太紧，改 `PRELOAD`（弹簧预压，默认 0.2mm）或 `SPRING_T`（横梁厚度）；前框盖在玻璃四边上，背面有放玻璃的凹槽：屏幕凹进去太多或太少，改 `SKIN`（盖住玻璃那层的厚度）；玻璃顶住前框或板子压不紧，改 `STANDOFF`（玻璃正面到 PCB 安装耳正面）或 `GLASS_FIT`；玻璃放不进凹槽，改 `POCKET_GAP`、`FPC_TOP`（上沿排线）；开窗露出的黑边不均匀，改 `GLASS_DX` / `GLASS_DY`（玻璃相对安装孔的偏移）或 `BLACK_TOP / BLACK_BOT / BLACK_SIDE`；黑边想宽一点或窄一点，改 `VIEW_MARGIN`；插头位置不够，改 `EDGE_TOP / EDGE_BOT`；支架太紧或太松，改 `PEG_BARB`；孔位对不上，改 `HOLE_DX / HOLE_DY`；盖子卡扣太紧或太松，改 `HOOK_B`（倒钩凸出量）；盖子晃，改 `LIP_TOL`（上下左右）或 `SNAP_SLACK`（前后，倒钩卡面余量；改小了板子顶得更紧，但打印偏差大时可能扣不上）；麦克风、喇叭、电池的卡点改 `CLIP_B`（电池卡不进去改 `BAT_GAP`）；右侧开口上下位置改 `SIDE_DY`，下沿高低改 `SIDE_BOT_UP`。

第一次先建环境：
```bash
cd case && python -m venv .venv && .venv/Scripts/python -m pip install manifold3d numpy pillow
```
改完运行下面这行，会重新生成 `stl/`、`preview/` 和 `外壳预览.blend`（双击就能在 Blender 里看装配效果、爆炸图和打印摆放；没装 Blender 会自动跳过，也可以用环境变量 `BLENDER` 指定路径）（macOS / Linux 把 `.venv/Scripts/python` 换成 `.venv/bin/python`）：
```bash
cd case && .venv/Scripts/python model.py
```
